# Digicyfr Image Alt Use Audit 0.1.0 — website draft

## English

**Find the alt value saved on each image use.** This free, open-source WordPress plugin scans saved image tags in published posts and pages. It separates missing alt from explicit empty, whitespace-only, present and invalid values, then links each finding back to its source for an editor to review. The scan is bounded and resumable, with clear incomplete and unsupported-coverage states. Administrators can filter a private report and export a guarded CSV. It never edits images or alt text and never fetches remote content.

An empty alt can be appropriate for a decorative image; the author must judge context. Theme featured images, CSS backgrounds, dynamic output, templates and referenced synced blocks are outside this saved-content scan. Tested locally with WordPress 7.1, PHP 8.3.33 and MariaDB 11.4.13. Requires WordPress 7.1+, PHP 8.3+ and InnoDB. Licensed GPL-2.0-or-later. Download the ZIP, upload it in Plugins → Add New → Upload Plugin, and follow the README. Updates are manual.

## Polski

**Znajdź tekst alt zapisany przy każdym użyciu obrazu.** Ta bezpłatna wtyczka WordPress open source skanuje zapisane znaczniki obrazów w opublikowanych wpisach i stronach. Rozróżnia brak alt, pusty alt, same odstępy, obecny tekst i nieprawidłową wartość, a następnie wskazuje redaktorowi źródło do sprawdzenia. Skan jest ograniczony i można go wznowić; stany niepełnego i nieobsługiwanego zakresu są wyraźnie oznaczone. Administrator może filtrować prywatny raport i eksportować zabezpieczony CSV. Wtyczka nie edytuje obrazów ani alt i nie pobiera treści zdalnych.

Pusty alt może być właściwy dla obrazu dekoracyjnego; autor musi ocenić kontekst. Obrazki wyróżniające motywu, tła CSS, dynamiczne treści, szablony i odwołania do bloków synchronizowanych są poza zakresem tego skanu zapisanej treści. Przetestowano lokalnie z WordPress 7.1, PHP 8.3.33 i MariaDB 11.4.13. Wymaga WordPress 7.1+, PHP 8.3+ i InnoDB. Licencja GPL-2.0-or-later. Pobierz ZIP, prześlij go przez Wtyczki → Dodaj nową → Wyślij wtyczkę i skorzystaj z README. Aktualizacje są ręczne.
